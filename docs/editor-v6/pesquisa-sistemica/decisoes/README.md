# Decisões arquiteturais (ADRs)

Sem decisões aprovadas nesta rodada. Somente a estrutura e o [modelo](ADR-000-MODELO.md) estão preparados.

Uma ADR existe para documentar **uma escolha baseada em evidências**, não para converter uma hipótese em obrigação. Estados válidos: PROPOSTA, ACEITA, REJEITADA, SUBSTITUÍDA.

Toda ADR deve citar pesquisa, experimento/medições, riscos nos outros módulos, alternativas rejeitadas, compatibilidade com projetos salvos, plano de rollback e critérios de revisão. Decisões de renderizador ou persistência que alteram comportamento devem ser aprovadas antes da implementação.
