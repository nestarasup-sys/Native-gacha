# Evidências e fontes

Índice de URLs oficiais e resultados **sanitizados**. Começar em [FONTES-OFICIAIS.md](FONTES-OFICIAIS.md).

**Não publicar:** caminhos pessoais Windows, retratos/frames de projetos, IDs de personagem/projeto, mídias proprietárias, documentos brutos, perfil `app-data`, credenciais ou relatórios com informações privadas.

Para cada benchmark: incluir SHA, ambiente e contexto sanitizados, hash irreversível da fixture, configurações relevantes, condição de cache, número de repetições, fases, resultado negativo/positivo, data e vínculo a experimento. Se ausente, marcar **NÃO MEDIDO**.
